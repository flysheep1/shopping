# 宝塔面板部署教程（自定义端口版）

本项目：前端 Vue3（构建后为纯静态文件）+ 后端 Node.js Express（lowdb 存本地 JSON）。

**端口说明（重点）：**

| 服务 | 默认端口 | 自定义方式 |
|------|---------|-----------|
| 后端 API | 3000 | 环境变量 `PORT`，如 `PORT=3001` |
| 前端开发模式 | 5173 | 仅本地开发用，生产环境不需要 |
| 网站访问 | 80/443 | 宝塔创建站点时自己填 |

生产环境推荐做法：**前端构建成静态文件由 Nginx 托管，后端只监听本机端口，通过 Nginx 反向代理 `/api`**。这样浏览器只访问一个域名，不存在跨域，后端端口也不用对外开放。

---

## 一、环境准备

1. 宝塔面板 → 软件商店 → 安装：
   - **Nginx**（任意版本）
   - **Node.js 版本管理器**（安装 Node 18+，本项目后端用了 ESM 和 lowdb v7，建议 18 以上）

2. 确认 Node 可用（SSH 终端执行）：

```bash
node -v    # 应输出 v18.x 或更高
npm -v
```

> 如果提示找不到命令，在 Node 版本管理器里点"设置为命令行版本"。

---

## 二、上传代码

把项目上传到服务器，例如 `/www/wwwroot/shopping/`：

```bash
/www/wwwroot/shopping/
├── backend/
└── frontend/
```

可以用宝塔的"文件"功能上传压缩包后解压（**不要上传 node_modules 和 db.json**，服务器上重新安装依赖）。

---

## 三、后端部署（自定义端口，避开冲突）

### 1. 先检查端口是否被占用

```bash
# 任选其一
netstat -tlnp | grep 3001
ss -tlnp | grep 3001
```

没有输出 = 端口空闲，可以用。

### 2. 安装依赖

```bash
cd /www/wwwroot/shopping/backend
npm install --production
```

### 3. 生成一个强密钥（JWT_SECRET 必须设置）

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

把输出复制下来，下一步要用。

### 4. 用 PM2 启动（端口自定义，这里以 3001 为例）

```bash
# 方式一：命令行直接传环境变量（推荐，简单直接）
cd /www/wwwroot/shopping/backend
PORT=3001 JWT_SECRET=刚才生成的密钥 pm2 start server.js --name shopping-api

# 查看状态 / 日志
pm2 logs shopping-api --lines 20

# 设置开机自启
pm2 save
pm2 startup
```

看到 `Backend running at http://localhost:3001` 即成功。

> ⚠️ **注意：**
> - `db.json` 是按**当前工作目录**相对路径写入的，所以必须先 `cd` 到 backend 目录再启动，PM2 会记住 cwd。
> - 如果用 PM2 的 `cluster` 模式/`-i max` 多进程，**不要**！lowdb 是 JSON 文件存储，多进程同时写会损坏数据，务必用默认 fork 单进程模式。
> - 宝塔的"Node 项目管理器"插件也可以启动（在项目设置里填启动文件 server.js、运行目录 backend、环境变量 PORT 和 JWT_SECRET），效果等同，二选一即可。

### 5. 验证后端

```bash
curl http://127.0.0.1:3001/api/products
```

返回商品 JSON 列表 = 正常。

## 四、前端构建

前端构建**可以在本地电脑做**（省服务器资源），把生成的 `frontend/dist/` 上传到服务器即可。

```bash
cd frontend
npm install

# 部署到域名根路径（推荐）：
npx vite build --base=/

# 部署到子路径 /shopping/（默认行为，不用加参数）：
npx vite build

# 也可以用环境变量控制（写进 CI 更方便）：
VITE_BASE=/ npx vite build
```

构建产物在 `frontend/dist/`。

> 开发模式想换端口的话：`npx vite --port 5180`，这只影响本地调试，与部署无关。

## 五、宝塔创建网站 + 反向代理

1. 宝塔 → 网站 → 添加站点：
   - 域名：填你的域名（或 `IP:自定义端口`，端口自定义就在这里改，比如 8080）
   - PHP版本：**纯静态**
   - 数据库：不创建

2. 把站点的**运行目录指向前端静态文件**：
   - 假设站点根目录是 `/www/wwwroot/shopping-site/`
   - 将 `dist/` 里的**内容**（不是 dist 文件夹本身）放进去

3. **配置 `/api` 反向代理到后端**（关键步骤，让前后端同域名）：
   - 站点设置 → 反向代理 → 添加反向代理
   - 代理名称：`api`
   - 目标 URL：`http://127.0.0.1:3001`（对应你在第三步设置的端口）
   - 发送域名：`$host`

   或者直接编辑站点配置文件（`/www/server/panel/vhost/nginx/站点名.conf`），在 `server {}` 内加：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

4. **SPA 路由回退**（刷新 `/profile` 不 404）：站点配置文件里再加：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

## 六、防火墙与安全

- **只需要放行网站端口**（80/443 或你自定义的站点端口）。后端 3001 **不要**在宝塔防火墙/云服务器安全组里放行，让它只监听本机，通过 Nginx 代理访问，安全得多。
- 如果站点用了自定义端口（如 8080），记得在：
  1. 宝塔 → 安全 → 放行该端口
  2. 云服务商控制台 → 安全组 → 放行该端口

## 七、常用运维命令

```bash
pm2 list                    # 查看后端进程状态
pm2 restart shopping-api    # 重启后端
pm2 logs shopping-api       # 看实时日志

# 换端口：先删再建
pm2 delete shopping-api
cd /www/wwwroot/shopping/backend
PORT=3002 JWT_SECRET=你的密钥 pm2 start server.js --name shopping-api
# 然后同步修改 Nginx 反代里的目标端口并 reload

# 备份数据（就是这一个文件）
cp /www/wwwroot/shopping/backend/db.json /www/backup/db_$(date +%F).json
```

## 八、常见问题

| 问题 | 原因与解决 |
|------|-----------|
| 访问接口 502 | 后端没起来或端口不一致：`pm2 list` 看状态，对比 Nginx 反代端口和 `PORT` 是否一致 |
| 登录一直 401 | 忘了设置 `JWT_SECRET` 或换密钥后旧 token 失效（重新登录即可） |
| 数据丢了/写不进去 | PM2 启动时不在 backend 目录，`db.json` 写到别处了；`find /www -name db.json` 找一下 |
| 刷新页面 404 | 缺第七节的 `try_files` 回退配置 |
| 端口被占用 | `ss -tlnp \| grep 端口号` 找到进程，要么杀掉要么换端口 |
| 服务器 npm install 报错 | Node 版本过低，用 Node 版本管理器装 18+ |
